# ⚡ QuizBlitz

Мультиплеерная викторина с ИИ. Хост задаёт тему, игроки входят по коду и соревнуются в реальном времени.

## Фронтенд

Часть @Nonwire (вход, создание игры, лобби, профиль и история) реализована в светлом стиле Material 3 Expressive и подключена к существующим игровым экранам @karapuz1226.

```sh
cd frontend
npm ci
npm run dev
```

Проверено: production-сборка и все 10 браузерных тестов, включая два клиента на реальном Socket.IO-сервере.

По умолчанию — локальное демо. Настоящие аккаунты и серверная история подключаются после готовности REST-бэкенда команды. Подробности запуска, API и live-режима: [frontend/INTEGRATION.md](frontend/INTEGRATION.md). Краткая инструкция для передачи проекта: [ГОТОВО.md](ГОТОВО.md).
