# QuizBlitz — часть @Nonwire готова

Сделана фронтенд-часть 1: главная, вход/регистрация/гость, создание комнаты, лобби, настоящий QR-код, профиль и история. Дизайн — светлый Material 3 Expressive. Существующие игровые экраны второго фронтендера подключены и сохранены.

## Посмотреть

На Mac: открыть `Запустить QuizBlitz.command`, затем Local URL из терминала.

Или:

```sh
cd frontend
npm ci
npm run dev
```

По умолчанию всё работает как локальное демо. Для просмотра достаточно создать игру с любым ником; для проверки гостевого лобби есть код **849215**. Реальный мультиплеер проверен на существующем Node-сервере. Реальные аккаунты/серверная история ждут REST-бэкенд команды.

## Передать в команду

- Все изменения только в `frontend` плюс эта инструкция и файл запуска.
- Локальная ветка: `feature/nonwire-lobby`.
- Готовая версия опубликована: https://github.com/lahmut-group/QuizBlitz. Это отдельный fork; исходный репозиторий команды не изменён.
- Полная инструкция, переменные окружения, API-форматы и границы интеграции: `frontend/INTEGRATION.md`.
- Проверки: из `frontend` выполнить `npm run build` и `npm run test:e2e`.
- Материалы и сценарии из задания использованы как требования к части @Nonwire; бэкенд и работу второго фронтендера не переписывали.

## Проверено

- Production-сборка проходит (`npm run build`).
- Все 10 браузерных тестов проходят, включая два клиента с реальным Socket.IO, переподключение и завершение демо-игры.
